# 💰 How Companies Think About Salary

The session explained the basic business model behind employment.

A company makes money by providing value.

If you can help a company:

* Solve problems.
* Build useful products.
* Improve systems.
* Increase revenue.
* Reduce costs.
* Grow an audience.
* Automate work.
* Build software.
* Improve productivity.

Then you are creating value for the company.

The company compensates you for the value you provide.

That compensation is your:

**Salary.**

### Simple model:

```text
Your Skills
     ↓
Your Work
     ↓
Value Created
     ↓
Company Benefits
     ↓
Compensation / Salary
```

This is why the focus of the cohort is strongly centered around **skills**.

# 🚫 No Backlog Piling

One of the biggest dangers in a cohort is creating a huge backlog.

The cycle looks like:

```text
Today's class
      ↓
"I'll do it tomorrow."
      ↓
Tomorrow's class
      ↓
"I'll do both later."
      ↓
More classes
      ↓
Huge backlog
      ↓
Overwhelmed
      ↓
Stop learning
```

### The rule:

# Don't let backlog pile up.

Do the work **today**.

# 🤖 How to Use GPT / AI Tools

AI tools are powerful, but the session emphasized an important approach.

### Don't immediately ask AI for the answer.

First:

1. Understand the problem yourself.
2. Think about possible solutions.
3. Try solving it.
4. Debug your own approach.
5. Then use GPT/AI when you need help.
6. Understand the AI-generated solution.
7. Implement it yourself.
8. Be able to explain it.

### The goal:

**Use AI as a tool for learning, not as a replacement for thinking.**

# 🌟 How to Become the Best Learner

## 1. Ask Crisp Doubts

Don't simply say:

> "I don't understand."

Instead explain:

> "I understood X, but when I tried Y, I got Z. Why is this happening?"

Good questions show that you attempted the problem.

---

## 2. Post Your Progress

Share your progress regularly.

Examples:

* GitHub links.
* Screenshots.
* Projects.
* Assignments.
* Learning updates.
* Progress posts.

Use the Discord threads to document daily progress.

# 📸 Show Your Progress — Even on Bad Days

Not every day will be perfect.

Some days you will:

* Feel tired.
* Get stuck.
* Make mistakes.
* Understand slowly.
* Have bugs.
* Solve fewer problems.

### Don't only document successful days.

Document the difficult days too.

# 💪 Embrace Hard Topics
