Q.2 # Can you explain your AI-powered movie discovery platform? What was your role, and how did the application work?

One of my main projects is an AI-powered movie discovery platform.

The main goal of the project was to make it easier for users to discover movies and get personalized recommendations.

I worked on both the frontend and backend. For the frontend, I used React.js and Tailwind CSS, and I used Zustand for state management. For the backend, I used Node.js and Express.js, with MongoDB for storing application data.

I integrated the TMDB API to get movie information, and I also used Gemini AI to provide personalized movie recommendations. I implemented JWT-based authentication and worked with REST APIs to connect the frontend with the backend.

One of the main challenges was managing data between the frontend, backend, and external APIs. I handled the API responses, loading and error states, and made sure the data was displayed correctly in the UI.

Overall, this project gave me practical experience in building a complete application from the frontend to the backend and database, and it also helped me improve my debugging and API integration skills.
